## 影响范围

| 变更作用域 | 作用域内调用 | 已确认调用方 | 候选引用 | 接口/数据/外部依赖 | 置信度 | evidence_refs |
|---|---|---|---|---|---|---|

`caller_candidates`、`symbol_references` 和 `api_references` 必须经过源码确认才能写入“已确认调用方”。

每条影响结论和测试点必须携带 `evidence_refs`：

```json
[{"file": "path/File.java", "line": 12, "scope_id": "optional", "kind": "diff|ast|confirmed_caller|candidate"}]
```

无文件锚点（`file` + `line` 或 `scope_id`）的结论必须写入「待确认」，不得写成已确认影响。

## 回归范围

- 核心回归：与变更作用域共享入口、状态、接口或数据的流程。
- 定向回归：已确认的具体消费者和相邻边界。
- 不回归：只有在存在明确隔离证据时才能列出。
